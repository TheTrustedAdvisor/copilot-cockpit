# Konfigurationsreferenz

## Laufzeit
- APP_ENV: Umgebung (dev, test, prod)
- APP_PORT: HTTP-Port
- LOG_LEVEL: Logging-Level

## Datenquellen
- DB_URL: Datenbankverbindung
- CACHE_URL: Cache-Verbindung
- API_BASE_URL: Externe API-Basis

## Security
- AUTH_ISSUER: Issuer URL
- AUTH_AUDIENCE: Ziel-Audience
- SESSION_SECRET: Session-Schlüssel

## Betriebsparameter
- REQUEST_TIMEOUT_MS: Timeout für Requests
- RETRY_COUNT: Wiederholungsversuche
- RATE_LIMIT_PER_MIN: Rate-Limit
