# Quickstart (Happy Path)

## Ziel
In 15-30 Minuten zur ersten erfolgreichen Nutzung.

## Voraussetzungen
- Laufende Zielumgebung
- Zugriffsdaten vorhanden
- Datenquelle erreichbar

## Schritte
1. Anmeldung durchführen
2. Basis-Konfiguration setzen
3. Verbindung zur Datenquelle testen
4. Erste Abfrage ausführen
5. Ergebnis validieren

## Verifikation
- Antwort enthält valide Nutzdaten
- Keine kritischen Fehler im Log
- UI zeigt erfolgreichen Lauf
