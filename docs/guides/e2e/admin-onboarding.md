# End-to-End Pfad: Admin Onboarding

## Ziel
Inbetriebnahme und erster erfolgreicher Datenabruf.

## Voraussetzungen
- Zugriff auf Zielumgebung
- Gültige Admin-Rolle
- Konfigurierte Datenquelle

## Schritte
1. Anmeldung im Cockpit
2. Konfiguration prüfen
3. Datenquelle verbinden
4. Testabfrage ausführen
5. Ergebnis validieren

## Erfolgsnachweis
- Anfrage liefert Daten ohne Fehler
- Logs enthalten keine kritischen Einträge
